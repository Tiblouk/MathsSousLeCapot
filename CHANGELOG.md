# Historique des versions

Ce fichier résume les changements visibles de chaque version publiée de
**Maths Sous le capot**.

## 0.1.1 - 29 septembre 2026

### Ajouts

- recherche locale des cours par texte et par tags pédagogiques ;
- écran « Mon parcours » avec statistiques et historique progressif ;
- profils locaux multiples avec progression indépendante ;
- défis, score local et classement entre les profils de l'appareil ;
- couleurs et badges indiquant les cours lus et les sessions sans faute ;
- score d'entraînement attribué une seule fois par cours et difficulté ;
- traductions des nouvelles interfaces en français, anglais, espagnol, italien
  et japonais.

### Améliorations

- chargement différé des données et des interfaces secondaires ;
- résumé local compact pour afficher les badges sans relire tout l'historique ;
- stockage portable organisé par profil ;
- documentation de l'architecture, de l'état du projet et du packaging mise à
  jour.

### Validation

- 265 tests automatisés réussis ;
- builds Windows et Android réussis sans avertissement ;
- version portable Windows autonome générée et démarrée avec succès.

## 0.1.0 - 28 septembre 2026

- première version portable publiée ;
- socle .NET MAUI pour Windows et Android ;
- cours disponibles des Fondations au Lycée ;
- entraînements, contrôles intermédiaires et corrections détaillées ;
- thèmes et traductions JSON.
